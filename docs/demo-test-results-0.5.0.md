Physical voice navigation, noisy-room latency, mixed DPI and broader applications remain unaccepted.

## New build boundaries

One-click conversation, local endpoint detection, faster preview polling, the companion dock, clipboard shelf, native rich answers and a managed OpenCode workspace UI are built. The initial physical test was blocked by the stopped development app; the user has now confirmed accurate words and both consecutive turns in the restarted published build. Microphone capture and this two-turn rearm test are accepted separately from broader voice/task-steering tests.

OpenCode still uses its own provider authorization and explicit model selection. ChatGPT login is not copied into it and grants no Gmail or Slack authorization. OpenClicky's custom AG-UI envelope and native renderer do not constitute a full CopilotKit/OpenDots/OpenIntelligentUI runtime, streaming protocol client or 3D renderer. Composio/Nango setup is researched, not connected.

No signed installer, clean-machine install, general desktop reliability or full requested product parity is accepted here.
