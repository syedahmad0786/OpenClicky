# HeyClicky video acceptance matrix

Recorded 12 October 2026 from the retained review package in [`artifacts/research/heyclicky-2026-10-12`](../artifacts/research/heyclicky-2026-10-12/) and [`heyclicky-video-review-2026-10-12.md`](heyclicky-video-review-2026-10-12.md).

This is a requirements matrix for OpenClicky, not a claim that the demonstrations are reliable product tests. The supplied links resolve to 13 unique videos. Times below are approximate sampled timeline locations: they identify the interaction to review, not every encoded frame. The review used one-second samples for the official clips, two-second full-timeline sheets, and six three-second action sheets plus a ten-second full-timeline sheet for the 32:10 independent review. No claim is made that every encoded frame was viewed.

Evidence labels:

- **Frame** means the behavior is visible in retained frame sheets.
- **Narration** means a spoken or captioned claim without enough visible proof.
- **Promo** means montage, branding, testimonial, pricing, referral, or other promotional context.

Current status refers to OpenClicky as of 12 October 2026. Acceptance IDs are intentionally stable so implementation and manual test notes can refer to the same requirement.

## Acceptance rules

1. A frame observation is a requirement signal, not proof that OpenClicky implements it.
2. A narration or caption can motivate a test but cannot upgrade a feature to accepted.
3. Promotional montage, pricing, testimonials and dashboard numbers remain context only.
4. Desktop acceptance requires the visible destination control and resulting state on Windows. Logs, planner output, API success and a running process are insufficient.
5. Screen pixels and microphone audio leaving the machine must be disclosed for any provider path; credentials and sign-in remain manual.
6. Confirm-each stays the default. Auto/Full require a visible warning, and a running task's access snapshot cannot silently widen.
7. The independent DaVinci recording is evidence for contextual teaching and manual editing; it is not evidence of autonomous video editing.
