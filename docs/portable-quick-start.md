# Welcome to OpenClicky 0.2

Open **OpenClicky.exe** on Windows 11 x64. This portable app includes its runtime.

Try **Pointing demo** and **Test desktop actions** first. These offline demonstrations do not need an account. Review each action before approving; the test window should show one green-button click and the exact text `hello`.

For AI assistance, open **Settings → Connection**, enter your own OpenRouter key, and save. Type in Ask or hold **Win+Alt+Space** while speaking. Typed requests allow three seconds to select your target app. Agent mode asks before each desktop input action. **Stop** or **Escape** cancels a task.

Closing Home keeps the app in the tray. Double-click the tray icon to reopen Home. Use the tray menu's **Quit** to exit.

Screen requests send all connected monitors to your selected provider. Local Windows speech and spoken replies are the defaults; optional cloud transcription sends recorded audio too. Optional plaintext Talk history is enabled by default and can be disabled or cleared in Settings. Keys are stored securely rather than in settings JSON.

This is an unsigned Windows preview. Local desktop checks have passed; live AI calls, a physical microphone, signed installation, and full HeyClicky feature parity are not accepted yet. ChatGPT sign-in remains experimental.

Source, build instructions, verification details, and issue tracking: [OpenClicky on GitHub](https://github.com/syedahmad0786/OpenClicky). The files in this folder may contain local changes newer than the published repository.
